# 站内 AI 助手（Agent）· 方案与待确认项

> 状态：**方案已确认，已进入实现**（2026-11-05）。入口=侧栏第 8 个「助手」；模型=DeepSeek 官方 Key；可写数据；MVP 非流式；范围 A。站点已恢复到 1.1.0、功能完整可用；WIP 代码保留在 `js/agent/`，未接入路由。
> 相关文档：[技术契约](agent-spec.md)

## 1. 一句话结论

可以给这个纯静态站点加一个**能真正操作数据的 Agent**：不用后端，浏览器直连 OpenAI 兼容端点（DeepSeek 已确认 CORS 通过），用户自带 API Key（BYOK）。它不只会聊天，还能查进度、搜题库、加单词、建素材、排任务、记练习。

## 2. 目标与边界

**要做成什么**

- 侧栏新增「AI 助手」：对话 + 工具调用 + 工具轨迹 + 设置。
- Agent 能读写工作台现有数据，复用 `store`、480 道口语题库、素材引擎。
- 默认接 DeepSeek，也可换任意 OpenAI 兼容端点（含本地 Ollama / LM Studio）。
- Key 只存本机浏览器，不进导出 JSON、不进日志、不发往本项目服务器。

**明确不做**

- 不做账号体系、不代管额度、不做云端中转（保持纯静态）。
- 不提供删除类工具；删除仍由用户在对应页面操作。
- 不把 480 道答案/范文打包进提示词（按需工具检索，避免 token 爆炸）。

## 3. 技术路线

```
浏览器（静态站）
  ├─ Agent UI（聊天 / 设置 / 工具轨迹）
  ├─ Agent Core（OpenAI tools 循环，最多 6 轮）
  ├─ Tools（get_overview / search_vocab / add_vocab / ...）
  ├─ 现有 store（localStorage）与素材引擎
  └─ fetch → https://api.deepseek.com/v1/chat/completions
                Authorization: Bearer <用户 Key>
```

- 已验证：`OPTIONS https://api.deepseek.com/chat/completions` 返回
  `access-control-allow-origin: http://localhost:8899`、允许 `authorization,content-type`。
- 所以**不需要代理**。若用户换到不允许 CORS 的端点，可选加一个本地小代理（Node 20 行），但不是 MVP 必需。
- 对话与配置都存 `localStorage`；Key 与工作台导出的 JSON 隔离。

## 8. 需要你确认的 5 件事

1. **入口**：侧栏第 8 个模块「助手」（推荐）／右下角浮动球／两者都要？
2. **模型与 Key**：DeepSeek 官方 Key（推荐，CORS 已验证）／本地 Ollama（免费、离线）／其他 OpenAI 兼容服务？
3. **写权限**：Agent 可直接写（加词/建素材/排任务，均有活动日志）／只读，改动需你手动确认？
4. **流式输出**：MVP 先非流式（更简单稳定）／一开始就做流式打字机？
5. **范围**：只做 A（推荐先上）／直接做 B（评分、RAG、多会话）／先不写代码？

## 10. 成本与隐私

- **费用**：按你填的模型服务商计费；日常问答通常每天几分到几毛钱，长文批改更高。页面会显示每次 token 用量。
- **Key**：只存当前浏览器；导出 JSON 不含 Key；可在设置里一键清除。
- **对话内容**：直接发给你填的模型服务商，不经过本项目任何服务器。
- **离线**：没有 Key 或断网时，Agent 不可用，但工作台其他功能完全不受影响。

## 11. 风险与备选

| 风险 | 应对 |
|---|---|
| 用户没有 Key | 设置页给获取链接；支持本地 Ollama；无 Key 时显示引导 |
| 模型乱改数据 | 工具白名单、无删除、每次写操作有活动日志；可加「执行前确认」开关（决策点 3） |
| token 成本/上下文爆炸 | 工具结果截断 2000 字符；只按需检索；最多 6 轮 |
| 端点不支持 CORS | 可选本地代理脚本（不默认启用） |
| 浏览器缓存旧页面 | 已有 `?v=` 版本号 + 设置页「部署自检」 |
